# Phase 6 — Oracle 0.6.0

## 本阶段变更

- 九个页面分为三组，每组最多四个原版 tabs；使用原版 option cycle 切换组。
- 补齐八个原版 toggle：启用、自动刷新、抽牌顺序、未来商店、补充包、优惠券、高级信息、实际验证。预测深度为 3 / 5 / 10 / 20。
- 隐藏功能时跳过对应页面读取。关闭未来商店仍可查看当前已经生成的商品；关闭自动刷新保留缓存失效，手动刷新或换页重新读取。
- 高级随机序列页按 key 排序，每页六行，读取当前真实 pseudorandom 的标量值；不调用随机函数。数字以 17 位有效数字显示。
- 高级预览 tooltip 补充底注、重掷次数、包/商品位置。技术字段默认关闭；本机已有高级信息偏好被保留。
- configuration.lua 独立补齐旧配置缺失字段，不覆盖已有有效开关和深度。新增中英文本地化条目。

本阶段不更改 RNG 生成算法，沿用已验收的 0.5.4 预测边界；Experimental 条件分支仍然明确标注。

新增回归覆盖旧配置迁移、全部设置控件和深度选择、九页分组与禁用状态、已排队自动刷新取消、隐藏页面不执行读取、当前商店保留、优惠券过滤，以及 RNG 页的排序、分页、返回数据隔离和 keyed/global RNG 不变。
