# 生成、复制与目标小丑快捷预览

0.16.0 复用已有 shadow Joker adapter、缓存和实际触发验证器，补齐原版 tooltip 入口；没有再实现一套 RNG。只对当前持有的小丑显示预测，商店、收藏和 Oracle 渲染的预览牌不触发此功能。

| 小丑 | 展示 |
| --- | --- |
| 卡牌术士／流浪者／第六感／通灵 | 下一次满足原版触发条件后生成的塔罗或幻灵牌 |
| 帕奇欧 | 当前消耗牌中的复制目标，以及带负片的结果 |
| 证书 | 随机生成扑克牌的点数、花色、蜡封 |
| 偶像 | 当前点数与花色 → 下次目标 |
| 古老小丑 | 当前花色 → 下次花色，排除当前花色 |
| 邮件返利／城堡 | 当前点数或花色 → 下次目标 |
| 乌合之众／超位置／大理石小丑 | 对应生成牌 |
| 待办清单／疯狂 | 下次牌型目标／销毁目标 |

所有文字附在原版说明下方，使用现有本地化、颜色、tooltip 与字号。生成牌保留版本、贴纸、蜡封等名称；无空位、无复制目标或被削弱时显示原因。主页面的偶像等目标也同时展示当前与下次值。

## 原版行为与边界

真值来自当前本机 Balatro 1.0.1o、Steamodded 26.829.0 的实际 Lua 函数。原版 end_round 在 Boss 胜利后先提高底注，再执行 reset_idol_card / reset_ancient_card 等。快捷预览依据 round_resets.blind_states 判断下次结算用的底注，避免商店仍残留上一个 Boss 对象导致重复加底注。跳过小盲注／大盲注的路径也参与判断。主页面仍可手动选择刷新底注。

这是下一次单独合格触发的条件预测，不是整手计分或完整回合模拟。先触发的小丑、复制效果、重复触发、购买／出售／使用牌或修改牌组可能改变结果；改变后再次悬浮会按最新快照刷新。目标预览默认下一次待打盲注被击败；如果之后又跳过盲注，需要重新查看。

所有适配器接收深拷贝快照并使用独立 RNG。UI 不调用真实随机函数。缓存签名涵盖快照与底注请求；不在每帧运行完整预测。既有原版生成／复制／目标／蜡封 Expected vs Actual 观测继续有效。

## 自动验证

新增 20 组 seed × 10 类生成、复制或牌型效果，与原版 calculate_joker 事件队列比较结果及 RNG；12 组 seed × 4 类目标 × 7 种盲注状态，与原版目标刷新函数比较。检查悬浮文本包含实际牌名与属性、缓存复用、牌组／栏位／持牌变化失效、预览不修改真实快照、商店／收藏牌不展示结果。保留既有多 seed 概率、候选池、复制版本、只读与撤销回归。

完整图形界面的新悬浮效果仍需实机验收；自动测试不等同于实际游戏验收。
